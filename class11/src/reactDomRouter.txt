React Router DOM :

- install react router dom "npm i react-router-dom"
- in main.jsx "import {BrowserRouter} from 'react-router-dom'
- wrap <App/> by BrowserRouter in main.jsx file
- In App.jsx "import {Route,Routes} from 'react-router-dom'
- make <Routes> (collection of all route ) and inside <Routes></Routes> make <Route/>
- In <Route /> mention path (where to go) and elements (What to render) attributes
- In Navbar use <link> tag  by 'react-router-dom' to use redirect to any specific route
- make Navbar components as well and add it before <Routes> in App.jsx

- Nested Routes can be made by writting in this way - path="/product/men"
- Dynamic Routes can be made by writting this way - path="/product/:id"

- You can access id by using useParams() hook inside that element you rendered in a Dynamic Route
